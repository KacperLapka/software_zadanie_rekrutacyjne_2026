## 4. Bit-reversal + CRC

`protocol.py:74-76,62-71`:

1. Pack `header+values+payload` (10B).
2. Reverse bits in every byte: `int(f'{byte:08b}'[::-1],2)`.
3. `calculate_crc(data)`:
   * Pad with `b'\x00'` to multiple of 4.
   * Reinterpret LE `I*` as BE via `struct.pack('>'+fmt, *struct.unpack(fmt,data))`.
   * `Crc32Mpeg2.calc(...).to_bytes(4,'little')`, appended.
4. Decode: split `data[:-4]/data[-4:]`, compare CRC else `ChecksumMismatchError` (`protocol.py:42-44`), then bit-reverse, then `_unpack` (`protocol.py:53-60`): split off 4B payload, strip 1B header, unpack values, re-derive `data_type` to pick payload fmt.

`bitstruct.Error` -> `ProtocolError` on both paths.

## 5. Manager Behavior

`communication_manager.py:29-30,82-119,121-151`:

* Priority queue: `{HIGH:deque, LOW:deque}`. `push()` appends by `frame.priority`. `pop()`/`send()` drains `HIGH` first. `send()`: `pop()->encode()->transport.write()`, returns frame (or `None`).
* `connect()` clears queues, calls `transport.open()`. `disconnect()` closes.
* `register_callback(cb,frame)`: exact-`Frame` key; if `destination==BROADCAST`, expands via `create_broadcast_callback_keys()` (`communication_manager.py:159-169`) to one key per `BoardID` (stops at `LAST_BOARD`, skips `BROADCAST/GRAZYNA`) with `source` substituted, using `as_reversed_frame()` (swap src/dst, `frame.py:95-104`).
* `receive()`: decode, then `callbacks[frame](frame)`; `KeyError` -> `UnregisteredCallbackError`.
* Only `TransportType.TCP` supported in `change_transport_type()` (`communication_manager.py:39-48`); else `TransportError`.

## 6. TCP Transport

* `TcpSettings(address,port)`: IPv4 regex validate + `0<=port<=65535`.
* `open()`: `socket(AF_INET,STREAM).connect((addr,port))`, then `settimeout(0)` (non-blocking), `_socket_open=True`.
